Something
unexpected?

Some accidents make good pictures. Others need fixing.

Report a problem

Use the public GitHub issue tracker for bugs, questions and ideas. You’ll need a GitHub account to post. Search existing issues first — someone may have found the same thing.

Report a bug ↗Browse issues ↗

Issues and attachments are public. Do not post private photographs, email addresses, payment details or other sensitive information.

What helps

  • Your iPhone model and iOS version.
  • The Gleitzsch version and build number from ⓘ → About.
  • What you did, what happened and what you expected.
  • The preset or copied recipe values, if the problem concerns a particular effect.

Attach a screenshot only if you’re comfortable sharing everything visible in it.

Testing through TestFlight?

You can also send feedback through Apple’s TestFlight app. This avoids posting it to the public issue tracker. Apple supplies submitted feedback and available diagnostics to the developer under its TestFlight privacy terms.

Have an idea?

Share the picture you wish you could make, or the part of the camera that feels awkward. This is a small personal project, so replies and changes may take a little time.

Quick start

Random
Continuously changes the effect settings.
Presets
Choose Rainbow, VHS, Old TV, Crosscolor, Bad Day or Echo Chamber, or a saved C1–C3 mix.
Custom
Stops random adjustments and opens the current settings. Tap the heart to save a mix; use the saved-slot menu to replace or delete it.
Framing and saving
Landscape fits the captured frame with rounded preview corners. Translucent Random, Presets and Custom buttons float over the picture; capture controls sit to its right. The corner mask and controls are only part of the preview and are not saved in your photograph. Portrait fills the screen with a centered crop. Saved photographs keep the full captured frame. The next app update adds the Gleitzsch app name, version and project website to saved photo file metadata. Sharing services may remove this metadata.
