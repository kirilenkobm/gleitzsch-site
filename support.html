Support / feedback

Something
unexpected?

Some accidents make good pictures. Others need fixing.

Report a problem

Use the public GitHub issue tracker for bugs, questions and ideas. You’ll need a GitHub account to post. Search existing issues first — someone may have found the same thing. Issues aren’t only for things that broke — ideas for another way to mess the picture up belong here too.

Report a bug ↗Browse issues ↗

Issues and attachments are public. Do not post private photographs, email addresses, payment details or other sensitive information.

Email support

For support or privacy questions, email bogdan.kirilenko+gleitzsch@proton.me. You can also use Contact support in the app’s About screen. It opens a draft with the app and iOS versions; nothing is sent automatically. If no mail app is available, use Copy email.

Only include photographs or attachments you want to share with the developer. For public bug reports and ideas, GitHub Issues remains available.

What helps

  • Your iPhone model and iOS version.
  • The Gleitzsch version and build number from ⓘ → About.
  • What you did, what happened and what you expected.
  • The preset or copied recipe values, if the problem concerns a particular effect.

Attach a screenshot only if you’re comfortable sharing everything visible in it.

Testing through TestFlight?

You can also send feedback through Apple’s TestFlight app. This avoids posting it to the public issue tracker. Apple supplies submitted feedback and available diagnostics to the developer under its TestFlight privacy terms.

Have an idea?

If you know another way to mess the picture up, suggest it. A reference helps: a still, a clip or a link you’re comfortable leaving public. You can also describe a part of the camera that feels awkward. This is a small personal project, so replies and changes may take a little time.

Quick start

Random
Continuously changes the effect settings. Rotating the phone keeps Random running.
Presets
Choose Iridescence, VHS, Old TV, Broken Air, Echo Chamber or Pixelate, or a saved C1–C3 mix. Direction follows your phone: Vertical in portrait, Horizontal in landscape. Rotating keeps the selected preset. TV and CRT lines continue to follow the display.
Custom
Stops random adjustments and opens the current settings. Tap Save to save a mix; use the saved-slot menu to replace or delete it. Reset clears the adjustments. Swipe the Custom panel down to close it.
Barrel
In Custom, gently bulge the image while keeping the rectangular frame filled, or set it to 0 for a flat picture. It works in both directions, with the same result in the preview, photographs and videos.
Pixelate
Choose Pixelate for a pixelated look. You can adjust the pixel size and add other effects in Custom.
Screen
The lock button beside the shutter keeps the screen awake while the camera is open. Tap it again to let the screen sleep. It starts off each time you open Gleitzsch.
Switch camera
Tap the camera button beside the flash to switch between the front and rear cameras.
Shutter
Tap for a photograph. Hold for a moment to start a silent video: the shutter pulses and becomes a red square. Release your finger to keep recording; tap the red square to stop. A clip keeps the orientation and glitch direction it started with. Leaving the camera or an interruption ends the recording.
