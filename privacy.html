Privacy policy

This policy describes the current Gleitzsch iPhone camera and this project website, maintained by Bogdan Kirilenko.

Image processing

Gleitzsch processes camera images on your iPhone. The app does not upload your images or effect settings to the developer or to a server. It does not require an account. We add no advertising, tracking, analytics or crash-reporting services of our own. Apple’s system services and TestFlight may handle diagnostics as described below.

All image effects run on your device using conventional signal-processing algorithms. No AI, no neural networks. The app does not send images to an AI service or use them to train models.

Camera and Photos permissions

Camera access provides the live preview and lets you create glitched photographs. The app does not request microphone or location access.

When you save a result, Gleitzsch requests add-only access to Photos. It can add your photograph without reading or browsing your existing photo library. Photos manages saved images and may sync them through iCloud Photos if you have enabled it; Gleitzsch does not perform that sync.

The next app update adds the Gleitzsch app name, version and project website to saved photo file metadata. It does not add author, location or user/device identifiers. Sharing services may remove this metadata.

You can change permissions in iOS Settings.

Saved photo file metadata includes the Gleitzsch app name, version and project website. Gleitzsch does not add author, location or user/device identifiers. Sharing services may remove this metadata.

Local settings and saved mixes

Current effect settings and C1–C3 mixes are stored locally. Reset clears the current effect settings. Saved slots remain until you replace or delete them. These local settings may be included in device backups managed by your operating system.

Deleting a mix does not delete photographs already saved to Photos. Manage those photographs in Photos.

TestFlight and Apple diagnostics

If you install a beta through TestFlight, Apple handles installation, testing information, crash reports and feedback according to its own terms. Apple may make beta diagnostics and feedback available to the developer. This is separate from the app’s on-device image processing.

See TestFlight & Privacy. Feedback received by the developer is used to understand problems and improve Gleitzsch.

Support and public issues

Support is currently provided through GitHub Issues. If you post an issue, your GitHub profile, message and attachments are public. Only share material you intend to publish. A GitHub account is required to post; it is not required to use the app.

Issue content is used to answer questions and investigate bugs and may remain as a public project record after an issue is closed. GitHub manages its storage and account data under its privacy statement. For a question about this policy, open an issue without including sensitive personal information. TestFlight testers can use TestFlight feedback instead.

This website

This is a static website prepared for GitHub Pages. It contains no analytics scripts, advertising, embedded social feeds, third-party fonts, forms, cookies or browser storage set by this site.

When served through GitHub Pages, GitHub receives technical request information, such as your IP address, to deliver the pages. Its privacy statement applies to that hosting. Following a link to GitHub, Apple or another service takes you to a service with its own privacy practices.

Changes

This policy will be updated if the app’s features or data practices change. The date at the top identifies this version.
